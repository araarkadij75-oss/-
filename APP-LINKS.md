# Постоянные ссылки EliteService

Используйте эти адреса как основные. Они привязаны к постоянным путям GitHub Pages, поэтому новые публикации приложения обновляют содержимое по тем же адресам, без `release`, `fresh` и иных временных параметров.

- Владелец: https://araarkadij75-oss.github.io/-/preview/v18.17.21/
- Диспетчер-логист (Сергей и Артём): https://araarkadij75-oss.github.io/-/preview/v18.17.21/dispatcher-logistic.html

Не выдавайте сотрудникам owner-ссылку как рабочую: доступ всё равно проверяется Firebase по учётной записи и роли. Адрес страницы не заменяет авторизацию.

Техническая доступность зависит от GitHub Pages и Firebase. Если в интерфейсе отображается «Подключение…», это ошибка или незавершённое состояние синхронизации, а не повод менять постоянную ссылку.
